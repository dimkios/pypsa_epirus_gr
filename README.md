# PyPSA Epirus GR

Εφαρμογή μοντελοποίησης και βελτιστοποίησης του δικτύου ηλεκτρικής ενέργειας της **Περιφέρειας Ηπείρου** (Ελλάδα), με χρήση [PyPSA](https://pypsa.org/) και [Streamlit](https://streamlit.io/). Αναπτύσσεται σταδιακά ως εκπαιδευτικό project — βλ. [devplan.md](devplan.md) για το πλήρες πλάνο ανάπτυξης.

## Τι κάνει η εφαρμογή

Η εφαρμογή:
1. Δείχνει σε διαδραστικό **χάρτη** τους πραγματικούς κόμβους (υποσταθμούς, υδροηλεκτρικούς σταθμούς, Κέντρα Υπερύψηλης Τάσης) και τις γραμμές μεταφοράς της Ηπείρου, όπως προκύπτουν από επίσημα στοιχεία του ΑΔΜΗΕ.
2. Χτίζει ένα **μοντέλο βελτιστοποίησης PyPSA** πάνω σε αυτό το δίκτυο, για μία τυπική ημέρα (24 ωριαία στιγμιότυπα), και υπολογίζει πώς θα έπρεπε να κατανεμηθεί η παραγωγή ώστε να καλύπτεται η ζήτηση με το ελάχιστο κόστος.
3. Επιτρέπει στον χρήστη να **πειραματιστεί με σενάρια** μέσω sliders: προσθήκη νέας ισχύος ΑΠΕ, περιορισμός εισαγωγών ενέργειας από το υπόλοιπο σύστημα, μεταβολή ζήτησης, προσθήκη μπαταρίας αποθήκευσης — και να δει άμεσα πώς αλλάζει το αποτέλεσμα.
4. Περιλαμβάνει ένα **εκπαιδευτικό panel** που εξηγεί κάθε βασική έννοια του PyPSA (Bus, Generator, Load, Link, StorageUnit, snapshots) μαζί με τον πραγματικό κώδικα και τα πραγματικά δεδομένα του δικτύου.

## Τι βλέπεις στην οθόνη

| Ενότητα | Τι δείχνει |
|---|---|
| **Χάρτης δικτύου** | Οι 17 κόμβοι της Ηπείρου (χρωματισμένοι ανά Περιφερειακή Ενότητα) και οι 21 γραμμές μεταξύ τους. Στο hover κάθε κόμβου φαίνεται ο τύπος του και το επίπεδο αξιοπιστίας των συντεταγμένων του. |
| **Σενάριο** | 4 sliders για να αλλάξεις τις παραδοχές του μοντέλου πριν τρέξει η βελτιστοποίηση: νέα ισχύς ΑΠΕ (MW), μέγιστες επιτρεπτές εισαγωγές (MW), μεταβολή ζήτησης (%), ισχύς μπαταρίας (MW). |
| **📚 Πώς φτιάχνεται το μοντέλο PyPSA** | Εκπαιδευτικά tabs (Bus / Generator / Load / Link / StorageUnit / Snapshot & optimize()) — κάθε ένα εξηγεί την έννοια, δείχνει τον κώδικα που τη χτίζει, και τον αντίστοιχο πίνακα με τα πραγματικά δεδομένα του δικτύου, όπως διαμορφώθηκαν από τα sliders. |
| **Βελτιστοποίηση PyPSA** | Το αποτέλεσμα του `network.optimize()`: γράφημα παραγωγής ανά γεννήτρια ώρα-ώρα (stacked area), ημερήσιο ισοζύγιο ζήτησης/παραγωγής/εισαγωγών σε MWh, στάθμη μπαταρίας αν έχει προστεθεί, και αναλυτικοί πίνακες (ροές γραμμών, δεδομένα εισόδου) σε αναδιπλούμενες ενότητες. |

### Πώς να διαβάσεις το αποτέλεσμα
- **Status: Optimal** (στο log του solver) σημαίνει ότι βρέθηκε εφικτή λύση με το ελάχιστο δυνατό κόστος παραγωγής.
- Ο solver προτιμά πάντα πρώτα τις φθηνότερες πηγές (**merit order**): ΑΠΕ (μηδενικό κόστος) → υδροηλεκτρικά (χαμηλό κόστος) → εισαγωγές από το υπόλοιπο σύστημα (ακριβότερες, χρησιμοποιούνται μόνο αν χρειάζεται).
- Αν οι "Εισαγωγές συστήματος" είναι 0, σημαίνει ότι η Ήπειρος καλύπτει την εκτιμώμενη ζήτησή της αποκλειστικά με δικές της πηγές.

## ⚠️ Τι είναι πραγματικό και τι εκτίμηση

Το project δίνει προτεραιότητα σε πραγματικά δεδομένα όπου είναι δυνατόν:

| Στοιχείο | Κατάσταση | Πηγή |
|---|---|---|
| Κόμβοι, γραμμές, ισχύς υδροηλεκτρικών | ✅ Πραγματικά | ΑΔΜΗΕ, Δεκαετές Πρόγραμμα Ανάπτυξης Συστήματος Μεταφοράς |
| Εγκατεστημένη ισχύς ΑΠΕ (~522MW) | ✅ Πραγματικά | ΑΔΜΗΕ, μητρώο σταθμών ΑΠΕ |
| Ηλιακό προφίλ διαθεσιμότητας | ✅ Πραγματικά | PVGIS (Ευρωπαϊκή Επιτροπή), δορυφορικά δεδομένα ακτινοβολίας |
| Ζήτηση ανά Περιφερειακή Ενότητα | 🔶 Εκτίμηση (βελτιωμένη) | 60% πραγματικό ΑΕΠ (Eurostat) + 40% πραγματικός πληθυσμός (ΕΛΣΤΑΤ) — μεθοδολογία pypsa-eur, όχι μετρημένη κατανάλωση |
| Σχήμα ημερήσιας καμπύλης ζήτησης | 🔶 Παραδοχή | Τυπική καμπύλη με 2 αιχμές (πρωί/βράδυ), όχι μετρημένο προφίλ Ηπείρου |
| Προφίλ διαθεσιμότητας αιολικών | 🔶 Απλοποίηση | Χρησιμοποιείται προσωρινά το ίδιο ηλιακό προφίλ PVGIS |

Κάθε αρχείο δεδομένων στο `data/processed/` έχει στήλη `confidence` και `source_note` που τεκμηριώνει ακριβώς την πηγή κάθε τιμής.

## Πώς να το τρέξεις

### Προαπαιτούμενα
- Python 3.11+ (δοκιμασμένο με 3.13)
- Git

### Βήματα
```bash
# 1. Κλωνοποίησε το repo
git clone https://github.com/dimkios/pypsa_epirus_gr.git
cd pypsa_epirus_gr

# 2. Δημιούργησε virtual environment
python -m venv .venv

# 3. Ενεργοποίησέ το
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 4. Εγκατέστησε τα dependencies
pip install -r requirements.txt

# 5. Τρέξε την εφαρμογή
streamlit run app/streamlit_app.py
```

Η εφαρμογή θα ανοίξει αυτόματα στον browser σου στο `http://localhost:8501`. Αν δεν ανοίξει μόνη της, επισκέψου το link χειροκίνητα.

### Αν κάτι δεν δουλέψει
- **Σφάλμα σχετικό με solver**: η εφαρμογή χρησιμοποιεί τον open-source solver [HiGHS](https://highs.dev/), ο οποίος εγκαθίσταται αυτόματα μέσω του `pip install -r requirements.txt` (πακέτο `highspy`) — δεν χρειάζεται ξεχωριστή εγκατάσταση.
- **Ελληνικοί χαρακτήρες εμφανίζονται λάθος στο terminal**: είναι μόνο θέμα εμφάνισης της κονσόλας (Windows codepage) — μέσα στην εφαρμογή (browser) εμφανίζονται κανονικά.
